State-Space Analysis

Transfer functions describe one input and one output. State space describes everything happening inside, which is why it scales to multiple inputs, multiple outputs and computer control.

  • Choose state variables for a circuit or a mechanical system and write the state equations.
  • Solve the state equation with the matrix exponential and interpret each term.
  • Read stability, natural frequencies and damping from the eigenvalues of A.
  • Derive the transfer function from (A, B, C, D) and explain pole–zero cancellation.
  • Test controllability and observability with the rank of the controllability and observability matrices.
Start with a question

A two-state system has eigenvalues at −2 and +1. Its transfer function, after a cancellation, looks like a simple stable first-order lag. Is the system stable? The answer depends on whether you are allowed to see the unstable mode — and that is a question about observability, not about the transfer function.

9.1 What a state variable is

A state variable is a quantity that stores energy or memory: the voltage across a capacitor, the current through an inductor, the position and velocity of a mass. The complete set of state variables at time t summarises everything about the past that is needed to predict the future. Given the state and the future inputs, the future is determined.

The state-space model writes the system as a set of first-order differential equations plus an output equation:

Continuous-time state modelCORE
ẋ(t) = A x(t) + B u(t),   y(t) = C x(t) + D u(t)
  • x state vector, n × 1
  • A state matrix, n × n
  • B input matrix, n × m
  • C output matrix, p × n
  • D feedthrough matrix, p × m

The dimensions must match: A is square with one row per state, B has one row per state and one column per input, C has one row per output. D is often zero because most physical systems cannot respond instantly.

The first-order form is not a restriction. Any n-th order differential equation can be rewritten as n first-order equations by choosing the derivatives as states. The reward is that numerical integration, matrix analysis and computer control all work with first-order systems.

For discrete time the derivative becomes a difference: x[k+1] = A x[k] + B u[k]. The same matrices appear, and the same stability question becomes |λi| < 1 instead of Re(λi) < 0.

Worked example 9.1

An RC circuit in state space

A series RC circuit has input voltage u and output voltage across the capacitor. Choose the capacitor voltage as the state.

KVL. u = Ri + v_C, and i = C dv_C/dt.

State equation. C dv_C/dt = (u − v_C)/R, so v̇_C = −v_C/(RC) + u/(RC). Therefore A = −1/(RC), B = 1/(RC).

Output. y = v_C, so C = 1 and D = 0.

Numbers. With R = 1 kΩ and C = 1 µF, RC = 1 ms, so A = −1000. The eigenvalue −1000 is the pole at s = −1000, the time constant is 1 ms and the system is stable.

9.2 The matrix exponential and the state transition

For a constant input the solution of the state equation separates into a zero-input response and a zero-state response:

State solutionCORE
x(t) = eAtx(0) + ∫₀teA(t−τ)B u(τ)dτ
  • eAt state transition matrix
  • x(0) initial state
  • ∫… the forced response, a convolution with the input

The transition matrix is the matrix analogue of eat. It satisfies d(eAt)/dt = A eAt and eA·0 = I.

If A can be diagonalised, A = VΛV−1 and eAt = V eΛtV−1. Each diagonal entry of eΛt is eλit, so each eigenvalue contributes one mode. The eigenvectors in V determine how much of each mode appears in each state.

A repeated eigenvalue with only one eigenvector produces a Jordan block and a term t eλt. A complex conjugate pair produces a damped sinusoid. The matrix exponential therefore packages every qualitative behaviour the system can exhibit.

9.3 Eigenvalues are the poles

The eigenvalues of A are the roots of det(sI − A) = 0, which is exactly the denominator of the transfer function. This is not a coincidence: both describe the natural modes of the same system.

For a 2×2 matrix the characteristic polynomial is s² − (trace A)s + det A. Two numbers, the trace and the determinant, determine the poles. For higher orders, Routh–Hurwitz or a numerical root finder is used.

  • All eigenvalues in the left half-plane: stable; every mode decays.
  • A pair on the imaginary axis: marginally stable; sustained oscillation.
  • Any eigenvalue in the right half-plane: unstable; that mode grows.
  • Complex pair σ ± jωd: oscillation at ωd, decay at rate |σ|.

The trace is the sum of the eigenvalues and the determinant is their product. These identities are quick checks when you compute poles by hand, and they survive a change of state coordinates.

9.4 From state space to a transfer function

Take the Laplace transform of the state equations with zero initial conditions. Then sX = AX + BU and Y = CX + DU. Eliminating X gives:

Transfer function from state spaceCORE
H(s) = C(sI − A)−1B + D
  • (sI − A)−1 the resolvent matrix
  • C…B selects the input-to-output path
  • D the direct feedthrough term

The denominator of H(s) is det(sI − A). If a zero of the numerator cancels a pole, that mode is present in the state but invisible at the output.

This formula explains the hook at the start of the module. A state-space system can be internally unstable while its transfer function looks stable, if the unstable mode is unobservable or uncontrollable. Such a system is called internally unstable but input–output stable. In practice it is dangerous: the hidden mode can saturate an actuator or destroy the plant even though the measured output looks well behaved.

Realisation is the reverse problem: given H(s), find matrices that produce it. The controllable canonical form and the observable canonical form are standard constructions. They are not unique — infinitely many state choices produce the same input–output behaviour — but they all share the same eigenvalues.

Worked example 9.2

Transfer function from two states

Let A = [0 1; −6 −5], B = [0; 1], C = [1 0], D = 0. Find H(s).

Characteristic polynomial. trace = −5, det = 0·(−5) − 1·(−6) = 6. So det(sI − A) = s² + 5s + 6 = (s+2)(s+3).

Numerator. Compute C adj(sI − A) B. For this companion form the result is 1, so H(s) = 1/[(s+2)(s+3)].

Check. The DC gain is 1/6. The impulse response is the inverse Laplace of the expression, a difference of two exponentials. Both poles are negative, so the system is stable.

9.5 Controllability and observability

A state is controllable if an input can drive it to any desired value in finite time. A state is observable if its value can be deduced from the output over time. Both are rank tests on matrices built from A, B and C.

Controllability and observability matricesTEST
𝒞 = [B   AB   A²B  …],   𝒪 = [C; CA; CA²; …]
  • rank 𝒞 = n fully controllable
  • rank 𝒪 = n fully observable
  • n number of states

For a single-input, single-output second-order system, both tests reduce to a nonzero determinant. A zero determinant means at least one mode cannot be reached or cannot be seen.

Controllability is about actuators; observability is about sensors. A system can be controllable but not observable (you can steer it but not measure where it went) or observable but not controllable (you can measure it but not affect it). Neither property is required for stability, but both are required for most control and estimation designs.

The popov–Hautus tests are the modern form: the pair (A, B) is controllable if and only if no left eigenvector of A is orthogonal to B. The matrix rank test and the eigenvector test answer the same question; the rank test is easier to compute by hand, the eigenvector test is easier to interpret.

9.6 Discrete-time state models

A digital controller updates the state once per sample: x[k+1] = Adx[k] + Bdu[k]. The continuous matrices are converted using the matrix exponential, Ad = eAT, and an integral of the same exponential for B. The eigenvalues map as zi = eλiT.

This mapping preserves the stability boundary: a continuous pole in the left half-plane maps inside the unit circle. It also preserves damping and oscillation frequency, but it aliases frequencies above the Nyquist rate, exactly as Module 8 predicted. A controller designed in continuous time and discretised at too low a rate can therefore behave very differently from its continuous prototype.

For hand calculations, the forward-Euler approximation Ad ≈ I + AT is often used. It is accurate only when the sampling interval is much shorter than the fastest time constant, and it can even turn a stable continuous system into an unstable discrete one if T is too large.

9.9 Simpler explain

Simpler explain

The state of a system is the smallest set of numbers you need to know right now to predict what it will do next. For a moving car, that is its position and its speed. For an RC circuit, it is the capacitor voltage.

The A matrix says how the states push on each other. The B vector says how the input pushes them. The C vector says which combination of states you can measure. Together they are a complete description.

The eigenvalues of A are the system's natural rhythms. Negative real eigenvalues mean decay; positive mean growth; imaginary pairs mean oscillation. A transfer function sees only the rhythms that are both reachable from the input and visible at the output. State space sees all of them, which is why it is the language of modern control.

Foundation check

For a diagonal A with entries −1 and −4, the states decay as e−t and e−4t. The slower mode dominates after a few seconds. The trace is −5 and the determinant is 4, so the characteristic polynomial is s² + 5s + 4 = (s+1)(s+4), which matches.

Deep dive

State space turns system theory into linear algebra. The matrix exponential is the semigroup of the dynamics; controllability and observability are rank conditions on invariant subspaces; the transfer function is a Schur complement of the resolvent. The same structures reappear in Kalman filtering, model predictive control and machine learning, where a hidden state is inferred from noisy observations. The vocabulary changes; the linear algebra does not.
