Module 1 Foundations 7 concepts

Signals and Systems

Before a signal can be transmitted it has to be described. Before a system can be designed it has to be classified. This module builds that vocabulary and makes each definition testable.

  • Represent a physical quantity as a function of time and distinguish continuous from discrete descriptions.
  • Test a signal for periodicity, symmetry, energy or power, and decompose it into even and odd parts.
  • Recognise the six basic signals and use the sifting property of the impulse.
  • Test a system for memory, causality, BIBO stability, linearity and time-invariance.
Start with a question

Two systems see the same input. One is described by y(t) = x(t − 1), the other by y(t) = x(1 − t). Both look like simple delays or reflections. Only one is time-invariant. Which one — and why does the difference matter when you build a filter?

Hold the question. By section 1.5 you will answer it by testing, not by guessing.

1.1 A signal is a function; a system is an operator

A signal is a function representing a physical quantity that carries information. The voltage across a capacitor, the pressure at a microphone, the brightness of a pixel and the position of a robot joint are all signals once they are written as functions of an independent variable. In this course the independent variable is usually time, written t for continuous time and n for discrete time. The dependent variable is written x(t) or x[n].

A system is a rule that maps an input signal to an output signal. Write the rule as an operator T:

System as an operatorDEF
y(t) = T{x(t)}
  • x(t) input signal
  • y(t) output or response
  • T{·} the rule the system applies

For discrete time the same rule is y[n] = T{x[n]}. The notation does not yet say the system is linear, causal or stable — those are separate properties that must be tested.

The distinction matters because the same physical object can be described at several levels. A resistor is a system whose output is a scaled copy of its input current. An RC circuit is a system whose output depends on the recent history of its input. A communication channel is a system that adds attenuation, delay, distortion and noise. Once the rule is written, the theory of this course applies to all of them.

→

Why the independent variable matters

A continuous-time signal is defined for every real value of t. A discrete-time signal is defined only at integer values of n, usually produced by sampling a continuous signal at uniform intervals Ts: x[n] = x(nTs). The sample index is dimensionless; the time of sample n is nTs. Confusing the index with the time is the source of many errors in later modules.

1.2 Classifying signals along independent axes

Signal classifications are not a single hierarchy. A signal can be continuous-time and digital, or discrete-time and analog, or both random and periodic. Treat each classification as a separate question with its own test.

Table 1.1 — Independent classifications and the test that decides each one

Continuous / discrete timeIs the independent variable defined for every real value or only at integers?Mains voltage is CT; a monthly average temperature is DT.
Analog / digitalCan the dependent variable take any value in a range, or only a finite set?Vinyl groove is analog; a 16-bit audio sample is digital.
Real / complexAre values real numbers, or do they have an imaginary part?A real sinusoid; a phasor Aejθ.
Deterministic / randomIs the value at every instant fixed by a rule, or described by a probability model?sin(ωt) is deterministic; thermal noise is random.

Periodic / aperiodicIs there a smallest positive T with x(t+T) = x(t) for all t?cos(2πf₀t) is periodic; a rectangular pulse is not.

Even and odd decomposition

Every signal — with mild technical conditions at points of discontinuity — can be written as the sum of an even part and an odd part. The construction is simple and worth memorising, because it separates a waveform's symmetric content from its antisymmetric content.

Even and odd partsM1
xe(t) = 12[x(t) + x(−t)],   xo(t) = 12[x(t) − x(−t)]
  • xe even part, xe(−t) = xe(t)
  • xo odd part, xo(−t) = −xo(t)
  • x original signal, x = xe + xo

The same formulas hold for sequences with n in place of t. The decomposition is unique.

Products and symmetryM1
even × even = even,   odd × odd = even,   even × odd = odd
  • even unchanged by time reversal
  • odd negated by time reversal

These rules let you predict the symmetry of a product before plotting it. They are used constantly in Fourier analysis, where even signals produce cosine terms and odd signals produce sine terms.

Worked example 1.1

Decompose a one-sided exponential

Given x(t) = e−2tu(t), find its even and odd parts and sketch them.

  1. Write the time-reversed signal. Since u(t) is 1 for t ≥ 0, x(−t) = e2tu(−t), which is nonzero only for t ≤ 0.
  2. Apply the decomposition: xe(t) = ½[e−2tu(t) + e2tu(−t)] = ½e−2|t|.
  3. For the odd part, xo(t) = ½[e−2tu(t) − e2tu(−t)]. For t > 0 this is ½e−2t; for t < 0 it is −½e2t. Equivalently xo(t) = ½ sgn(t)e−2|t|.
  4. Check: at t = 0, xe(0) = ½ and xo(0) = 0, so their sum is 1, which equals x(0⁺). At t = 1, xe = ½e−2 ≈ 0.0677 and xo = 0.0677; the sum is 0.1353 = e−2, as required.
Result. The even part is a two-sided exponential ½e−2|t|; the odd part is the same envelope with opposite signs on the two sides. The original signal is their sum.

Periodicity, energy and power

A continuous-time signal is periodic with period T if x(t+T) = x(t) for every t. The fundamental period T₀ is the smallest positive value for which this holds. A constant signal is periodic for every T, so it has no fundamental period. A discrete-time signal is periodic with period N if x[n+N] = x[n] for every integer n; N must be an integer.

Periodicity of a sum is more delicate than it looks. If x₁ has period T₁ and x₂ has period T₂, their sum is periodic only when the ratio T₁/T₂ is a rational number. The fundamental period is then the least common multiple of T₁ and T₂. For a discrete-time sinusoid cos(Ω₀n), the condition is that Ω₀/(2π) is rational.

Energy and average powerM1
E = ∫−∞∞ |x(t)|² dt,   P = limT→∞ 12T ∫−TT |x(t)|² dt
  • E total energy, joules for a voltage across 1 Ω
  • P average power, watts under the same convention
  • |x|² instantaneous power (normalised to 1 Ω)

A signal is an energy signal if 0 < E < ∞ (then P = 0); a power signal if 0 < P < ∞ (then E = ∞). A periodic signal with finite energy per period is a power signal, and its power may be computed over one period.

Power of a sinusoidM1
x(t) = A cos(ω₀t + φ)  ⇒  P = A²2
  • A peak amplitude
  • ω₀ angular frequency, rad/s
  • φ phase offset, radians

The result follows from averaging cos² over a period: the mean of cos² is ½. RMS amplitude is A/√2.

Worked example 1.2

Is this sum periodic?

Consider x(t) = cos(2π·3t) + cos(2π·5t). Find the fundamental period and fundamental frequency.

  1. The first term has period T₁ = 1/3 s; the second has T₂ = 1/5 s.
  2. Form the ratio T₁/T₂ = (1/3)/(1/5) = 5/3, a rational number, so the sum is periodic.
  3. The fundamental period is the least common multiple: the smallest T that is an integer multiple of both 1/3 and 1/5. The LCM of the fractions is 1 s.
  4. Hence f₀ = 1/T₀ = 1 Hz. The two components are the third and fifth harmonics of that fundamental.
Result. T₀ = 1 s, f₀ = 1 Hz. If the second frequency had been √2 rather than 5, the ratio would be irrational and the sum would not be periodic, even though both terms are.

1.3 The basic continuous-time signals

Six signals do most of the work in signals and systems. They are not arbitrary examples: every other signal can be built from them by scaling, shifting and superposition.

  • Unit step u(t): 0 for t < 0, 1 for t > 0. At t = 0 the value is undefined or taken as ½ by convention. It models a switch closing at time zero.
  • Unit impulse δ(t): a generalised function with unit area concentrated at the origin. It is not a function in the ordinary sense; its meaning comes from what it does inside an integral.
  • Ramp r(t) = t u(t): zero before zero, then slope 1.
  • Exponential e−atu(t): the natural response of a first-order system. For a > 0 it decays with time constant 1/a.
  • Sinusoid A cos(ω₀t + φ): the natural response of an undamped second-order system and the building block of Fourier analysis.
  • Rectangular pulse rect(t/T): 1 for |t| < T/2, 0 outside. Its Fourier transform is a sinc, which links time width to bandwidth.
Step and impulseM1
u(t) = ∫−∞t δ(τ)dτ,   δ(t) = du(t)dt
  • δ(t) unit impulse, area 1
  • u(t) unit step, height 1

The derivative is interpreted in the generalised-function sense at the jump. Scaling rule: δ(at) = δ(t)/|a|.

Sifting propertyM1
∫−∞∞ x(t) δ(t − t₀) dt = x(t₀)
  • x(t) test signal, continuous at t₀
  • t₀ location of the impulse

This is the single most useful property of the impulse. It says an impulse samples the signal at the point where it sits. Convolution and sampling both rest on it.

Worked example 1.3

Evaluate an impulse integral

Evaluate I = ∫−∞∞ (t² + 1) δ(2 − t) dt.

  1. The impulse is located where its argument is zero: 2 − t = 0, so t₀ = 2.
  2. By the sifting property, the integral equals the integrand evaluated at t₀ = 2.
  3. I = (2² + 1) = 5.
  4. Check the scaling rule. If the impulse is written as δ(2 − t) = δ(−(t − 2)) = δ(t − 2), the coefficient is 1 because the argument has slope magnitude 1, so no extra factor appears.
Result. I = 5. The impulse does not care about the shape of t² + 1 anywhere except at t = 2.

1.4 Discrete-time signals

A discrete-time signal is a sequence of numbers indexed by an integer. It may arise from sampling a continuous signal, from a naturally discrete process such as a daily reading, or from a numerical simulation. The index n has no units; if the sequence comes from uniform sampling, sample n occurs at time nTs.

The discrete-time unit impulse is δ[n] = 1 at n = 0 and zero elsewhere. The unit step is u[n] = 1 for n ≥ 0 and zero for n < 0. Unlike their continuous counterparts, both are perfectly ordinary sequences. Any sequence can be written as a sum of scaled and shifted impulses:

Impulse decomposition of a sequenceM1
x[n] = Σk=−∞∞ x[k] δ[n − k]
  • x[k] sample value at index k
  • δ[n − k] impulse centred at k

This identity is the discrete counterpart of the sifting integral. It is the starting point for the convolution sum in module 2.

Discrete-time periodicityM1
x[n] = cos(Ω₀n) is periodic ⇔ Ω₀2π = mN (rational)
  • Ω₀ discrete angular frequency, rad/sample
  • m, N coprime integers
  • N fundamental period in samples

Unlike a continuous sinusoid, a discrete sinusoid is not necessarily periodic. For example cos(3n) is aperiodic because 3/(2π) is irrational.

1.5 Classifying systems by testing, not by name

A system is memoryless if its output at any instant depends only on the input at that instant. It is causal if the output depends only on present and past inputs, never on future ones. It is stable in the bounded-input bounded-output (BIBO) sense if every bounded input produces a bounded output. It is linear if it obeys superposition, and time-invariant if a delay in the input produces exactly the same delay in the output.

These are five independent questions. A system can be causal and unstable, linear and time-varying, or stable and nonlinear. The tests below are written as procedures because the exam question is almost always a procedure, not a definition.

Linearity

For any inputs x₁, x₂ and any constants a, b:

T{ax₁ + bx₂} = aT{x₁} + bT{x₂}

Equivalently, test additivity and homogeneity separately. A system with a nonzero offset, such as y = x + 1, fails homogeneity: doubling the input does not double the output.

Time-invariance

If x(t) → y(t), then for every shift t₀:

x(t − t₀) → y(t − t₀)

Shift the input first, then apply the system; compare with applying the system first, then shifting the output. If the two results differ, the system is time-varying.

Causality

The output at time t may use x(τ) only for τ ≤ t.

For an LTI system, causality is equivalent to h(t) = 0 for t < 0. A system that uses x(t + 1) is noncausal and cannot run in real time, although it can be simulated offline.

BIBO stability

There exist finite M, K such that |x(t)| ≤ M for all t implies |y(t)| ≤ K.

For an LTI system the test is absolute integrability: ∫|h(t)|dt < ∞. The integrator y(t) = ∫−∞tx(τ)dτ is not BIBO stable because a constant input produces an unbounded ramp.

Worked example 1.4

Test y(t) = x(1 − t)

Decide whether the system is memoryless, causal, BIBO stable, linear and time-invariant.

  1. Memory: the output at t uses the input at 1 − t, which is generally not t; the system has memory.
  2. Causality: at t = 0, the output uses x(1), a future value. The system is noncausal.
  3. Stability: if |x| ≤ M, then |y| = |x(1 − t)| ≤ M; the system is BIBO stable.
  4. Linearity: T{ax₁ + bx₂} = ax₁(1 − t) + bx₂(1 − t) = aT{x₁} + bT{x₂}. Linear.
  5. Time-invariance: shift the input by t₀: T{x(t − t₀)} = x(1 − t − t₀). Now shift the original output: y(t − t₀) = x(1 − (t − t₀)) = x(1 − t + t₀). The two differ unless t₀ = 0. Time-varying.
Result. The system is linear, stable, noncausal, has memory and is time-varying. The sign of the t inside the argument is what breaks time-invariance; a pure delay x(t − 1) would be time-invariant.
!

Common error

Testing time-invariance by checking whether y(t) = x(t − 1) "looks shifted" is not enough. Write both sides: T{x(t − t₀)} and y(t − t₀). A system with a time-dependent coefficient, such as y(t) = t x(t), is linear but time-varying because the multiplier changes with the observation time.

1.8 Simpler explain

Simpler explain

A signal is just a quantity that changes — a voltage, a sound pressure, a temperature. Drawing it as a graph of value against time lets us talk about its size, its rhythm and its shape.

Some signals repeat exactly. The time one full repeat takes is the period; the number of repeats per second is the frequency. They are reciprocals: a period of 0.01 s means 100 repeats per second.

Any signal can be split into a part that is the same when played backwards (even) and a part that is exactly reversed (odd). This is not a physical trick; it is a bookkeeping device that makes Fourier analysis and convolution easier.

A system is a machine that turns an input signal into an output signal. The important properties are simple questions: does it remember the past, does it need the future, does it stay bounded, does it respect scaling and addition, and does it behave the same on Tuesday as on Monday? The answers are the five tests in section 1.5.

Foundation check

If x(t) is a voltage and x²(t) is its instantaneous power across a 1 Ω resistor, then the area under x²(t) is energy. A sine wave that never stops has infinite area (infinite energy) but a finite average height (finite power). This is why periodic signals are power signals, not energy signals.

Deep dive

The even/odd decomposition is the first example of a broader idea: projecting a signal onto orthogonal subspaces. The even and odd parts are orthogonal under the inner product ⟨f,g⟩ = ∫f(t)g(t)dt, and x = xe + xo is an orthogonal decomposition. Fourier series performs the same operation with sinusoids as the basis, and the z-transform does it with complex exponentials. Recognising the pattern now will make the transform chapters feel less like a collection of formulas.

  • Power: P = A²/2 for A cos(ω₀t+φ); energy signals have finite E and zero average power.
